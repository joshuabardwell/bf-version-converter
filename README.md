# bf-version-converter

Convert a Betaflight configuration (`diff all`, `dump all`, or a few CLI lines) from one firmware version to
another, upgrade or downgrade, and see exactly what changed and why.

**https://joshuabardwell.github.io/bf-version-converter/**

- Paste your CLI text; the converted text appears side by side with the original.
- Every line that needs your attention is marked `ATTENTION` inside the converted text, with the reason and
  how to set it again in the CLI. Everything else converts automatically.
- Supported: Betaflight 4.5, 2025.12 and 2026.6 (each patch release of those series).
- Your configuration never leaves your browser and isn't saved.

## How it works

The conversion runs in your browser (Python via [Pyodide](https://pyodide.org)). It applies version maps
built by a separate pipeline that compares the Betaflight sources of each release, with every conversion
tested by pasting converted configurations into Betaflight's simulator (SITL) and reading them back.

- `public/engine/` is generated by that pipeline (`bfmap bundle`): the converter's Python modules
  (`bfmap-engine.zip`), the per-version-pair data, and a manifest. **Don't edit it here**; fixes are made in
  the pipeline, tested, and re-bundled.
- The rest of this repository is the web app.
